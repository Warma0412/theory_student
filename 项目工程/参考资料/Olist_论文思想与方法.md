# 基于 AI 构造虚假数据（Knockoff）的电商 GMV 归因维度选择 —— 完整说明

> 用途：本文件供模型（如 Trae 内的 AI）通读后理解并执行整个研究流程。
> 内容包含：论文思想、数据背景、方法原理、AI 介入点、完整执行步骤、输出与稳健性。
> 数据集：Olist 巴西电商公开数据集，聚合为「卖家 × 月」面板，目标为 GMV（连续）。
> 约定：维度选择阶段不做同类压缩，保留全部原始候选维度进入模型。

---

## 一、论文思想（研究动机与核心逻辑）

### 1.1 研究问题
电商 GMV 归因看板上有大量候选维度：价格、运费、物流时效、支付方式、分期、评价、商品物理属性、卖家供给、营销来源等。看板位有限、维护有成本，核心问题是：

> **这些候选维度里，哪些真正驱动 GMV、值得占一个永久看板位？**

### 1.2 传统做法的根本缺陷
相关系数排序、单变量回归、经验判断等传统方法，缺少对**错误发现率（FDR，False Discovery Rate）**的控制。排出的 Top 维度里往往混入大量「只是碰巧和 GMV 相关」的假阳性维度，一旦放上看板会误导运营决策。

### 1.3 核心思想：用 AI 构造「虚假数据」来选维
本文采用 **Knockoff（仿制变量 / 虚假变量）** 方法。核心直觉：

> 与其纠结「某维度重要性够不够高」，不如给每个真实维度造一个「假替身」——一份**虚假数据**。这份假维度刻意保留与其他维度相同的相关结构，但在构造上与目标 GMV 没有任何真实关系。

于是判据变得干净利落：
- 真实维度重要性 **明显强过** 其假替身 → 该维度真有用；
- 真实维度重要性 **与假替身相当** → 该维度多半是假阳性。

用「真 vs 假」的对比卡阈值，就能在数学上**严格控制 FDR**——这是相比传统排序法的核心价值。

### 1.4 为什么用 Olist + 面板
- **Olist**：真实电商全链路数据，天然带物流、支付、评价、营销等大量「不同现象」的候选维度，维度足够丰富，能充分体现「选维」价值。
- **面板（卖家 × 月）**：让 GMV 成为平滑连续目标，并为深度时序模型提供「实体 × 时间」结构。

## 二、数据背景与结构

### 2.1 数据来源
- 主数据集 Brazilian E-Commerce Public Dataset by Olist：
  https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
- 营销漏斗 Marketing Funnel by Olist：
  https://www.kaggle.com/datasets/olistbr/marketing-funnel-olist

数据为真实脱敏的巴西电商交易记录，覆盖订单—商品—支付—物流—评价—营销全链路，可按月聚合成面板。

### 2.2 多表主键链路
```
orders(order_id, customer_id, 各阶段时间戳)
   └─ order_items(order_id, product_id, seller_id, price, freight_value)
           ├─ products(product_id, 品类, 物理属性, 照片数, 描述长度)
           └─ sellers(seller_id, seller_state)
   ├─ payments(order_id, payment_type, installments, sequential, value)
   ├─ reviews(order_id, review_score)
   └─ customers(customer_id, customer_state)
漏斗：closed_deals(mql_id, seller_id) ── mql(mql_id, origin)
```

### 2.3 目标变量
以「卖家 × 月」为面板单元，目标 y = 该卖家该月 GMV（sum of price），建议取对数（log1p）稳定方差。也可换成客单价、payment_value 做稳健性对照。

### 2.4 候选维度（不做同类压缩，全部保留）
按论文约定，维度选择阶段**保留全部原始候选维度**，每一列独立进入 Knockoff（约 20+ 个），包括但不限于：
- 价格类：price、freight_value
- 商品物理：weight、length、height、width、photos_qty、name_length、description_length
- 支付类：installments、payment_sequential、各支付方式占比（信用卡 / boleto / voucher）
- 口碑类：review_score
- 物流时效类：下单→审核、审核→发货、下单→送达、预计与实际时效差
- 供给类：成交件数、活跃品类数
- 地理类：seller_state、customer_state（频次编码或独热）
- 营销类（可选）：mql.origin

品类（product_category）等高基数标识作分组 / 固定效应，不单列为维度。

## 三、方法总览：核心方法 + AI 介入

### 3.1 核心方法
**Model-X / Deep Knockoff（构造虚假数据）做维度选择**：在控制 FDR 的前提下，筛出真正驱动 GMV 的维度。

### 3.2 AI 在本方法中的三处介入
1. **Deep Knockoff（AI 造虚假数据）**：当候选维度分布明显非高斯、且维度间存在复杂非线性相关时，用深度生成模型（如自编码器 / 生成网络，即 DeepKnockoffs 框架）学习真实维度的联合分布，并据此采样出「虚假数据」X̃。相比高斯近似，AI 生成的虚假数据更贴合真实分布，使选维更准、FDR 控制更可靠。
2. **TFT（AI 评重要性）**：用 Temporal Fusion Transformer 这类深度时序模型拟合「卖家×月 → GMV」，利用其内建的变量选择网络（variable selection network）输出每个维度的重要性权重，作为 Knockoff 统计量的重要性来源；也可单独给出深度模型视角的维度排序，与线性方法互相印证。
3. **e-values / 去随机化（AI 稳定结论）**：虚假数据的生成含随机性，单次结果会抖动。通过多次重复生成—选维，用 e-value 聚合各维度入选频率，得到稳定、可复现、且仍满足 FDR 控制的最终维度集合。

### 3.3 可选对照方法（非主线，仅作稳健性印证）
- **信息论 CMI + SAGE**：用条件互信息 / Shapley 值衡量维度对 GMV 的独立信息贡献。
- **因果不变性 ICP**：把州 / 时段当环境，检验维度与 GMV 的关系是否跨环境稳定。

若对照结论与 Knockoff 一致，写入「稳健性检验」章节增强说服力。

## 四、完整执行步骤（模型照此运行）

### 第 0 步：构造面板
将多张表按主键链路 join，聚合到「卖家 × 月」：实体键 = seller_id，时间键 = 下单时间截断到月；目标 y = 该卖家该月 GMV（取 log1p）；候选维度按卖家×月聚合（金额 / 时效 / 物理属性取均值，支付方式取占比，件数 / 品类数取计数），形成设计矩阵 X 与目标向量 y。样本区间取交易稠密段，首尾稀疏月留作敏感性分析。

### 第 1 步：标准化
对 X 的全部候选维度做标准化（均值 0、方差 1），保证后续重要性可比。

### 第 2 步：构造虚假数据（Knockoff 仿制变量）
- **高斯版（基线）**：估计 X 的协方差矩阵，构造仿制矩阵 X̃，使联合矩阵 (X, X̃) 的协方差满足 Knockoff 条件——X̃ 保留 X 的相关结构，但在给定 X 后与目标 y 条件独立。
- **Deep 版（AI 介入①，推荐）**：训练深度生成模型学习 X 的联合分布，采样得到 X̃。适用于维度非高斯 / 存在复杂非线性相关的情形。

### 第 3 步：计算重要性统计量 W
将真实 X 与虚假 X̃ 拼接（共 2×p 列）放入模型，对每个维度 j：

> **W_j = 重要性(真实 X_j) − 重要性(仿制 X̃_j)**

- 重要性来源可选：Lasso 系数绝对值（基线），或 **TFT 变量选择权重（AI 介入②）**。
- W_j 大且为正 → 真实维度明显强过假替身 → 可信；
- W_j ≈ 0 或为负 → 与假替身相当 → 很可能是假阳性。

### 第 4 步：按目标 FDR 卡阈值选维
给定目标错误发现率 q，用 Knockoff 阈值规则求最小 t，使

> (1 + #{W_j ≤ −t}) / max(#{W_j ≥ t}, 1) ≤ q

选出所有 W_j ≥ t 的维度，即「FDR ≤ q 下的可信维度集」。

### 第 5 步：e-values 去随机化（AI 介入③）
重复第 2～4 步多次（虚假数据每次重新生成），记录每个维度的入选频率，用 e-value 聚合，得到「稳定入选」的维度集合，消除单次随机性带来的抖动。

### 第 6 步：TFT 深度印证（可选）
训练 TFT 预测卖家×月 GMV，导出其变量选择网络权重，与 Knockoff 入选结果对照，看深度模型是否也认为这些维度重要，形成双重证据。

### 第 7 步：输出结论
对每个维度输出：W 统计量、入选频率（e-value）、是否最终入选。**最终入选集合即论文结论「值得永久上看板的维度」。** 未入选维度归为「下线」或「观察」。

## 五、结论与稳健性

- **结论落点**：在 FDR 控制下稳定入选的维度 → 建议永久上看板；其余下线或观察。
- **稳健性检验**：
  - 换 FDR 阈值（如更严 / 更松两档）；
  - 换目标变量（GMV vs 客单价）；
  - 换虚假数据生成方式（高斯 vs Deep）；
  - 裁剪首尾稀疏月；
  - 用 CMI / SAGE、ICP 交叉印证入选维度。
- **方法局限**：高斯 Knockoff 假设特征近高斯，Deep 版更稳；TFT 为进阶可选。应用论文层面，高斯版 + Lasso 已足够跑通，需要更强表达力时再升级到深度版本。

---

## 六、给运行模型的提示

1. 先完成第 0 步面板构造，确认 X（约 20+ 维，未压缩）与 y 就绪。
2. 以「高斯 Knockoff + Lasso 重要性 + e-values」为**基线主线**先跑通，产出维度入选表。
3. 若维度明显非高斯或需更强结果，再启用 **Deep Knockoff / TFT** 两处 AI 介入。
4. 最后用可选对照方法（CMI/SAGE、ICP）交叉验证，撰写稳健性章节。
5. 全程记录每一步的中间产物（面板、W 统计量、入选频率、最终维度集），供论文附录复现。
