# 无原始数据项目归档说明

本压缩包用于保存论文项目的文档、代码、配置、结果汇总、历史尝试和参考资料，不包含实际原始数据。

## 包含

- 当前项目总览和数据重建说明；
- V1至V7历史论文、代码、配置、图表和结果汇总；
- SCPL、Semi-KO条件矩、模型机制改动等方法研究；
- 正式V7论文、开题报告、开题汇报及LaTeX源文件；
- 71项方法登记表及历史报告快照；
- 数据源文件名、行数、字节数、SHA256和公开下载地址；
- 文档模板和参考资料；
- 审计JSON、汇总CSV、协议和关键源码；
- 空目录占位及`压缩排除清单.txt`。

## 不包含

- 项目根目录`原始数据/`中的任何CSV；
- 月度、周度等建模面板；
- `.parquet`、`.npz`、`.npy`等数据矩阵；
- 逐行预测CSV和逐案例大规模结果；
- Python虚拟环境；
- `__pycache__`及系统缓存；
- 模型权重与checkpoint；
- 第三方仓库`.git`历史；
- 第三方仓库附带的原始数据；
- 大型重复运行日志；
- 已下载的第三方源码压缩包。

## 为什么排除

这些文件可由公开数据、代码和固定种子重建，或属于本机环境和重复中间产物。排除它们可以明显减小体积，并避免重新分发原始数据。

## 如何恢复数据

先阅读：

1. `所有尝试与参考方法/项目必读.md`
2. `所有尝试与参考方法/数据来源与重建说明.md`
3. `项目工程/论文/v7/README.md`

从Kaggle获取两套Olist数据后，按说明放置十张CSV，再运行V7的`code/build_panel.py`。

## 归档可复现程度

本包能够：

- 查看全部主要论文、报告和方法结论；
- 检查方法代码、协议、汇总指标和审计文件；
- 在重新取得公开数据并安装依赖后重建主面板和重新运行实验。

本包不能：

- 在完全没有下载数据的情况下直接重跑全部真实数据实验；
- 恢复已排除的模型checkpoint；
- 恢复每个逐行预测或每份模拟矩阵；
- 保证第三方在线资源未来仍保持相同版本。

归档中的SHA256用于检查文件完整性，不构成数据使用许可。
