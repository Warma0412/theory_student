# 执行修订记录

本轮最初协议`protocol.json`不回写，保留初始摘要。以下修订不是根据哪个模型的测试误差更好挑选口径，而是检查出对所有方法都应纠正的可比性问题。已有初始结果保留，新结果另存。

## 1. 下游特征列规范排序

实际检查发现，“原Deep Lasso+Jacobian排名”和“Jacobian训练+原排名”在完整开发样本的Top-12集合与原Deep Lasso相同，但不同列顺序让下游随机列抽样或神经网络初始化产生了微小预测差别。这种差异不是选维收益。

修订：所有18种方法的K=8、12名单，以及31项全维基线，均在下游拟合前按固定特征编号排序。预测器架构、参数、种子和重拟合窗口不变；同一个变量集合复用相同预测。新增74组规范化预测文件在`results/canonical_predictions`。

不改变选择器的训练、参数、排名、名单或已完成的稳定性/FDP/Power。原40组新增预测与V7历史预测均保留，但最终RMSE表和配对区间以规范化版本为准。不会在两个版本中挑选对某方法有利者。

## 2. 共同模拟评价器

历史Copula-MVR的模拟下游评价器使用了秩高斯变换表示，其他方法使用标准化表示。因此，把它的模拟RMSE称为完全相同评价流程不准确。

修订：对全部600个模拟数据，保留所有18种方法的Top-12名单，使用训练期标准化、规范列顺序、同一个XGBoost参数与种子重新评价；相同集合复用同一拟合。结果保存在`results/canonical_simulation_evaluation`。这只改下游预测口径，不改选择器、真值和FDP/Power。

## 3. 并发调整

完成较快家族后，曾增加VTFS和门控家族的分片并发；后因系统压缩内存较多，下调VTFS并发。调整前结束旧分片，已完成JSON保留，未完成案例由新分片重算。

这些调整没有改变网络、训练轮次、样本、随机种子和规定重复次数。模型运行时间受系统负载影响，不能据此作严格等算力排名。

## 4. 结果性质

全部模型改动始于V7结果已知之后；这些修订同样属于执行期审计。它们提高内部可比性，但不能把整个研究转化为外部预注册或独立验证。新增算法是否原创，仍须相关工作辨析；是否普遍有效，仍须新数据确认。
