# V6相较V5改进说明

## 一、核心定位变化

V6不把贡献表述为提出新的Knockoff理论，而是把论文补强为一项完整、可审计的应用统计研究设计。正式推断仍只有Copula-MVR Model-X Knockoff、Lasso反对称统计量、60轮e-value聚合和e-BH这一条主线；新增方法只承担基准比较、组件消融或稳健性诊断职责。

## 二、改进明细

| 改进维度 | V5状态 | V6改进 | 主要结果或价值 |
|---|---|---|---|
| 标准方法基准 | 缺少统一协议下的横向比较 | 增加Elastic Net、稳定性选择、影子变量树模型、XGBoost-SHAP | 回答“为什么不用标准方法” |
| 比较公平性 | 各分支目的不同，不能直接比较 | 固定测试期前选维、12项预算、同参数XGBoost和同一测试期 | 排除信息泄漏和入选数量差异 |
| 评价指标 | 主要依赖预测误差和集合重合 | 同时报告RMSE、MAE、R2、WAPE、重抽样Jaccard、集合重合 | 区分预测、稳定性和错误率控制 |
| 真实数据结论 | 无法说明主方法是否优于基线 | SHAP的RMSE为2.383，Knockoff为2.392；统一子抽样下Elastic Net与Knockoff稳定性为0.873和0.855 | 如实说明SHAP预测略优，Elastic Net与Knockoff稳定性相近 |
| 已知真值模拟 | 仅有较窄的稀疏模拟 | 增加20轮、10个真信号、真实协方差模拟，并比较五种方法 | 可直接计算FDP与Power |
| 去随机化证据 | 60轮主要依赖理论动机解释 | 与单次Knockoff直接比较 | 平均FDP由0.145降至0.054，Power均为1.000 |
| S矩阵消融 | 只使用MVR主设定 | 比较MVR、SDP和等相关构造 | 证明S矩阵选择会改变发现集合 |
| 边际变换消融 | Copula与高斯主要作为稳健性结果 | 纳入统一消融表 | 原始高斯得到12项，与主集Jaccard为0.733 |
| 统计量消融 | Lasso和XGBoost结果分散 | 在同一消融协议中比较 | XGBoost统计量当前设定下无严格发现，复杂模型不自动提高功效 |
| 重复次数消融 | 只报告正式60轮结果 | 比较M=1、5、10、20、40、60 | 严格数为12、16、15、17、16、14，只有60轮与正式集合完全一致 |
| 方法定位 | 容易被质疑“算法拼装” | 明确每个组件对应混合边际、相关重构、负对照竞争或随机聚合 | 从方法罗列转为有职责和否决规则的研究设计 |
| 负结果处理 | 已保留深度生成器失败结果 | 将基准落后、零发现和阈值敏感性统一写入讨论 | 避免只报告有利结果 |
| 研究局限 | 主要讨论数据和模型假设 | 新增模拟轮数、信号设定和基线阈值依赖 | 防止把单一模拟外推为普遍方法排名 |
| 论文材料 | 论文、报告和汇报未含标准基准与消融 | 三类材料同步加入真实基准、消融和模拟 | 答辩口径与论文正文一致 |

## 三、V6最重要的事实结论

1. XGBoost-SHAP在统一测试中的RMSE最低，为2.383；去随机化Knockoff为2.392，二者差异很小。
2. 30组相同70%卖家子样本下，Elastic Net、去随机化Knockoff和XGBoost-SHAP的平均稳定性分别为0.873、0.855和0.686；Elastic Net与Knockoff的配对差异区间包含0。固定数据只更换Knockoff仿制变量所得0.969仅表示算法随机性。
3. 20轮模拟中，去随机化Knockoff平均FDP为0.054，单次Knockoff为0.145，二者Power均为1.000。
4. 稳定性选择在当前模拟中的平均FDP为0.090，表现具有竞争力；但它不提供当前Model-X设定下相同的有限样本FDR目标保证。
5. Elastic Net和影子变量树模型保持Power=1.000，但平均FDP分别为0.644和0.566，其高功效来自较多发现。
6. 60轮聚合不是装饰性重复。发现集合随重复数非单调变化，只有60轮与正式14项集合完全一致。

## 四、答辩建议口径

本文不宣称Knockoff在所有预测指标上优于现有方法。统一比较表明，XGBoost-SHAP的预测误差略低，但去随机化Knockoff的集合稳定性更高，并提供明确的错误发现率解释。组件消融进一步说明Copula、MVR、Lasso和多轮e-value聚合分别解决不同统计问题。因此，论文的创新是将公平比较、受控发现、参数化展示和多粒度复核组织为一套完整的应用统计研究设计。
