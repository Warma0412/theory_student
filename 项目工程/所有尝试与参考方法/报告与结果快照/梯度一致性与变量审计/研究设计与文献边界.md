# 变量质量与方法创新探索

## 1. 研究状态

本探索开始于V7全部测试结果已经查看之后。任何新增模型和指标只能作为后验探索，不能改写为预先注册的确认性证据。正式论文若采用新方法，需要使用新的时间窗口或第二数据集进行独立确认。

## 2. “变量好不好”不能只看一个指标

| 评价维度 | 实际问题 | 可计算指标 | 不能推出 |
| --- | --- | --- | --- |
| 样本外预测效用 | 保留它是否有助于预测下一期GMV | 固定K的时间外RMSE、MAE | 因果效应 |
| 条件必要性 | 在其他变量都在时删掉它是否变差 | 滚动月份的重拟合删除增量RMSE | 高相关变量的总业务价值 |
| 可替代性 | 删掉后是否容易被另一个指标替代 | 只用历史月份找替代、后续月份验证的替代遗憾 | 替代变量业务含义完全相同 |
| 卖家样本稳定性 | 更换卖家后是否仍被选中 | 互补半样本频率、Jaccard、Nogueira | 变量为真的概率 |
| 时间可迁移性 | 不同经营阶段是否持续有用 | 滚动月份删除增量为正的比例 | 永久有效 |
| 模型迁移性 | 是否只对某个预测器有用 | XGBoost、TabM等共同评价 | 模型无关的真理 |
| 冗余 | 是否重复表达其他指标 | 相关性、删除—替换试验 | 高相关变量必然无价值 |
| 错误发现 | 模拟中选错比例是否可控 | 已知真值下的FDP、Power | 真实业务FDP可直接观察 |
| 数据可用性 | 月末能否及时、稳定获得 | 缺失率、晚到率、修订历史 | 预测强就一定适合看板 |
| 可行动性 | 业务是否能据此采取行动 | 业务定义、责任归属、刷新成本 | 统计模型可自动量化全部业务价值 |

最终准入不应把这些指标随意加权为一个“总分”。预测、稳定、可替代性和数据可得性应分别列示，再按公开规则分类。

## 3. 相关真实文献

1. Cherepanova等（NeurIPS Datasets and Benchmarks 2023）提出Deep Lasso，以输入损失梯度组惩罚实现深度特征选择。V7已经直接调用作者正则函数。
2. Hédou等的Stabl发表于Nature Biotechnology 2024，明确区分predictivity、sparsity与reliability，并使用重抽样、噪声注入和数据驱动阈值筛选可靠候选变量。DOI：`10.1038/s41587-023-02033-x`。
3. Vareille等的ChronoEpilogi为NeurIPS 2024论文，强调预测问题可能存在多个同样有效的最小特征集合；只返回一个名单可能误导使用者。
4. EntryPrune（arXiv:2410.02344，2025年第4版）使用动态稀疏输入层、随机再生和entry-based pruning，并专门评价固定K和选择稳定性。它是近期真实方法，但目前检索到的是arXiv版本，不能写成已发表顶会论文。
5. ConsistentFeature（arXiv:2412.01476v2，2025）约束随机数据子集的表示差异。它说明“跨子集一致性正则”已有相邻研究，不能将任何简单一致性惩罚直接宣称为世界首创。

## 4. 初步模型改进

探索方法暂称“环境一致性Deep Lasso（EC-DeepLasso）”。对同一月份的卖家随机划分为互补两半，分别计算输入损失梯度分布，在Deep Lasso目标中加入两半归一化梯度分布的L1距离：

```text
总损失
= 两半预测损失均值
+ λ × 输入梯度稀疏惩罚
+ γ × 两半特征重要性分布距离
```

该构造的具体变化点是把一致性约束直接施加在“用于特征选择的输入损失梯度”上，并在同一月份比较互补卖家群。它与现有跨子集表示一致性和稳定选择有明显关联，因此目前只能称为方法改进候选。正式声称算法创新至少还需要：

- 更系统的文献检索；
- 明确优化性质或风险界；
- 新数据上的独立确认；
- 与原始Deep Lasso、ConsistentFeature式表示约束、稳定性集成和EntryPrune比较；
- 正则项、互补卖家和同月配对的组件消融。

## 5. 不以结果倒推创新

正则系数仅在V7训练和调参窗口内选择。规则为：先保留调参RMSE不超过最佳值1%的候选，再选择互补卖家Top-12名单Jaccard最高者；仍并列时选择RMSE更低、正则更小者。现有测试期已经被查看，只允许作为后验描述。

若规则最终选择`γ=0`，结论必须是“一致性正则没有在当前开发数据上提供增量价值”，而不是换阈值或改用测试集挑选一个看起来更好的结果。

## 6. 变量准入探索

变量审计覆盖四个结构不同且表现较强的方法：XGBoost-SHAP、Deep Lasso、TabM置换和影子变量树。对每项变量计算：

1. 四方法Top-12共识数；
2. 60个互补半样本中的平均、最低与最高出现频率；
3. 从31维模型删除该变量后的滚动月份RMSE变化；
4. 在某一方法Top-12中删除后，只根据历史月份选择最佳替代变量，再到后续月份验证；
5. 与其他变量的最大Spearman相关；
6. 月末可见面板中的缺失率。

探索性分类规则在查看审计结果前写入代码：

- **核心候选**：至少3/4强方法选中；半样本平均频率不低于0.70；完整模型删除后至少60%的月份误差变差；历史选择的替代变量在后续月份平均不如原变量。
- **可替代候选**：至少2/4强方法选中，但最大相关不低于0.80，或历史最优替代在后续月份不劣于原变量。
- **观察候选**：有部分选择或增量证据，但未同时通过核心规则。
- **证据不足**：当前窗口未形成足够一致的预测证据。

分类不是“真变量概率”，也不替代业务部门对口径、刷新成本和可行动性的审查。
