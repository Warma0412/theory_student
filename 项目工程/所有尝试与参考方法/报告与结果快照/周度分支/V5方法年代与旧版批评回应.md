# V5方法年代与旧版批评回应

## 1. 推荐论文题目

正式题目建议使用：

> 基于去随机化Model-X Knockoff的电商GMV多粒度受控维度选择研究

原题“面向电商GMV监控的多粒度可控维度选择研究——基于去随机化Model-X Knockoff、组级稳健性与可解释机器学习”过长，而且把主方法、稳健性分支和解释工具同时放入标题，容易产生“方法拼装”的第一印象。

新题目只保留真正承担确认性结论的核心方法。Group Knockoff、深度诊断、TreeSHAP和周度重跑继续在摘要、方法及稳健性章节中说明。

|---|---:|---|---|

| XGBoost | 2016 | 时间外预测基线 | 现代机器学习工具 |
| SHAP | 2017 | 确认集合内部的贡献排序 | 现代解释工具 |

## 3. 对旧版五条批评的事实回应

### 3.1 “方法像拼装组合”

状态：部分解决，但风险仍存在。

V5已经明确只有一条确认性主线：

> Copula预处理 → MVR Model-X Knockoff → Lasso反对称统计量 → 60轮e-value → e-BH。

参数K、XGBoost、TreeSHAP、卖家间/内分层、Group Knockoff、深度生成器和周度分析都不改变正式14项集合，只承担展示或稳健性验证。

仍然存在的风险是方法分支较多。答辩时若逐个宣称为“创新方法”，仍会被认为拼装。应始终称其为“一条主方法加多层诊断”，而不是多个并列模型。

### 3.2 “拼装方法的动机不清楚”

状态：基本解决。

每个模块已经对应一个明确风险：

| 数据或推断风险 | 对应方法 |
|---|---|
| 连续、计数、比例和二元变量混合 | 随机化秩高斯Copula |
| 协方差估计不稳定 | Ledoit-Wolf |
| 真变量与仿制变量可重构 | MVR |
| 单次Knockoff随机性 | 60轮e-value与e-BH |
| 页面展示数量不同 | 参数K |
| 共线代理变量互相替代 | Group Knockoff |
| 卖家重复观测 | 卖家均值—离差分层 |
| 非线性联合分布可能失配 | 深度核MMD和分类器检验 |
| 时间粒度可能改变结论 | 周度完整重跑 |

### 3.3 “与现有标准对比不够，指标不严谨”

状态：部分解决。

目前已经报告：

- FDR阈值、平均e-value、平均W和单轮入选频率；
- 模拟FDP与Power；
- Copula/高斯、目标定义、时间窗口和模型统计量敏感性；
- KS、协方差误差、MMD拒绝率和分类器AUC；
- 自然时间外RMSE、MAE、R²和WAPE；
- 月周交集、差集和Jaccard；
- 卖家间/内、业务组和轨迹重要性。

仍缺少一项强对照：在相同入选数量或相同误选预算下，与Elastic Net、Stability Selection、Boruta或条件置换重要性进行统一模拟比较。当前V5的诊断指标较严谨，但“优于现有变量选择方法”的证据仍不充分。

### 3.4 “参考文献老，内容经典”

状态：大部分解决。

确认性主线包含Model-X Knockoff（2018）、MVR（2022）、e-BH（2022）和去随机化Knockoff（2024）。稳健性分支还参考DeepDRK（2024）、聚类Knockoff（2026）和GRIP2（2026）。

BH、Lasso、Ledoit-Wolf和固定效应年份较早，但它们属于基础组件。论文不应把这些经典工具包装成创新；创新性应表述为经营看板问题上的统一研究设计、去随机化确认、参数化展示和多粒度证据体系。

### 3.5 “打不过已有方法怎么办”

状态：不能回答为“已经打赢”，必须调整论证目标。

V5并未证明在所有数据上优于现有方法。真实结果中：

- 默认K=10的月度RMSE为2.385，与全31维XGBoost的2.388基本一致；
- 周度18项XGBoost为2.421，全31维为2.420；
- 深度生成器未通过联合交换性诊断；
- MLP没有超过树模型；
- 卖家内层没有严格发现。

因此论文不能宣称“预测精度全面领先”或“深度方法优于传统方法”。合理贡献是：

1. 在压缩维度数量时基本保留预测性能；
2. 为入选集合提供目标FDR控制；
3. 将随机稳定性、跨粒度稳定性和生成器有效性纳入审计；
4. 如实报告深度模型和卖家内层的负结果。

若答辩要求证明方法优势，应补充统一模拟基准，在同一数据生成机制下比较FDP、Power、稳定性、预测误差、入选数量和运行时间，而不是只比较RMSE。
