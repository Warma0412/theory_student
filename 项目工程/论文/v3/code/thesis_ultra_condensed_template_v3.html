二、确认性主线：Copula-Lasso-eBH

预处理缩尾、偏态变换、插补、标准化、随机化并列秩。
负对照秩高斯Copula + Ledoit-Wolf协方差 + MVR。
竞争统计量[X,X̃]上Lasso，计算真实与仿制系数差。
FDR控制60轮Knockoff转e-value，最终执行e-BH。

1. Model-X生成与Lasso反对称性

Zᵢⱼ = Φ⁻¹[(rᵢⱼ − 0.5)/n]

秩高斯处理混合、偏态、离散和大量并列边际；MVR降低X被X̃重构的程度。

Wⱼ = |β̂ⱼ| − |β̂ⱼ₊ₚ|

交换Xⱼ和X̃ⱼ后Wⱼ变号；惩罚系数首轮交叉验证后固定。

H₀ⱼ: Yₛ,ₜ₊₁ ⟂ Xⱼ,ₛ,ₜ | X₋ⱼ,ₛ,ₜ

2. 去随机化与证据权限

步骤设定输出解释
单轮Knockoff+αkn=0.10用正负W失衡确定阈值
重复生成60个随机种子每轮入选转换为e-value并平均
最终e-BHαeBH=0.20严格集合承担FDR声明
稳定频率单轮频率≥90%只描述复现性，不等于FDR控制

三、深度Knockoff生成与交换性准入

1. 生成器结构

X̃ = Gθ(X, ε),　ε ~ N(0, I)

噪声条件生成器输入31维真实特征与同维高斯噪声，使用4层、宽度192的全连接网络，LayerNorm + GELU，输出经tanh限制极端值；AdamW训练，正式配置最多{{V2_GENERATOR_MAX_EPOCHS}}轮。

2. 训练目标：同时约束边际与联合交换

Swap-aware MMD
训练时随机交换20%、50%、80%特征，压低原始与交换联合分布差异。
矩结构
约束边际、均值、方差、协方差和交叉协方差对称性。
可重构性
将平均真伪成对相关推向约0.50，避免生成器复制X。
经验边际校准
只使用X的经验分位数，不读取Y；可修正边际，不能保证联合交换。

2. 面向后续研究的模型方向

  • 生成模型：优先尝试显式离散似然、条件normalizing flow或diffusion，减少事后边际校准，并预留独立测试集做交换性准入。
  • 重要性模型：增加配对MLP重复数、样本分割与交叉拟合；继续用结构约束和数值测试保证反对称性。
  • 预测模型：在更长企业面板上再比较TFT、N-BEATS等序列模型；当前19个月不宜强行上长序列架构。
  • 因果方向：对履约、内容和价格策略开展A/B实验、准实验或双重机器学习，不能把预测发现直接当干预收益。
最重要的V3结论：用户可自主设置K；模型默认推荐K={{V3_DEFAULT_K}}，测试RMSE相对全维变化{{V3_RMSE_CHANGE}}。统计确认与展示数量必须分层表达。
