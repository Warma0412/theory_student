二、预处理与Copula-MVR Knockoff

稳健处理1%/99%缩尾、偏态变换、中位数插补、标准化。
秩高斯固定种子打散并列秩，将混合边际映射到近似正态空间。
协方差Ledoit-Wolf收缩，降低高相关变量造成的病态估计。
MVR生成最小化可重构性，逐轮生成与真实特征竞争的负对照。

1. 为什么使用秩高斯Copula

金额、计数、比例、二元变量和大量并列值不适合直接套用原始高斯。对第j列按随机化秩映射：

Zᵢⱼ = Φ⁻¹[(rᵢⱼ − 0.5) / n]

该处理保留每列单调顺序，并用高斯Copula近似变量间依赖结构。它不是宣称原始变量服从正态分布，而是为二阶Model-X生成提供可计算空间。

2. MVR二阶Model-X生成

X̃ | X ~ N{ X(I − Σ̂⁻¹S), 2S − SΣ̂⁻¹S }

Σ̂由Ledoit-Wolf估计，S由MVR准则确定。理想仿制变量需满足成对可交换性，并在给定X后不再包含Y的信息。每轮只重新抽取X̃，不重新选择响应模型参数。

三、Lasso竞争、Knockoff+与e-value

1. 条件独立假设与反对称统计量

H₀ⱼ: Yₛ,ₜ₊₁ ⟂ Xⱼ,ₛ,ₜ | X₋ⱼ,ₛ,ₜ

在联合设计矩阵[X,X̃]上拟合Lasso，惩罚系数由首轮五折交叉验证确定，后续轮次固定。真实变量和仿制变量的系数绝对值之差为：

Wⱼ = |β̂ⱼ| − |β̂ⱼ₊ₚ|

交换Xⱼ与X̃ⱼ后Wⱼ变号，满足Knockoff所需的反对称性；较大的正W表示真实变量稳定胜过负对照。

2. 单轮阈值与60轮去随机化

单轮Knockoff+
按αkn=0.10寻找正负W失衡阈值；使用“1+负向数”控制偏乐观选择。
每轮e-value
入选变量获得与p/(1+负向数)成比例的证据，未入选变量记0。
重复60轮
不同随机种子重新生成X̃，逐变量平均e-value，降低单次仿制随机性。
最终e-BH
在αeBH=0.20下输出严格集合；单轮频率另作稳定性描述。
输出层定义是否承担FDR声明
严格确认集60轮e-value平均后通过e-BH是，在Model-X近似条件下
稳定候选集单轮入选频率≥90%否，只说明随机稳定性
预测解释层XGBoost、SHAP、固定效应否，用于交叉印证

2. 方法方向总结

  • 统计主线：自然粒度聚合 → 前瞻目标 → Copula-MVR Knockoff → Lasso反对称W → 60轮e-value → e-BH。
  • 机器学习主线：时间外XGBoost预测 + TreeSHAP解释；只承担预测验证，不替代FDR推断。
  • 面板主线：双向固定效应提供卖家内关联证据，仍需实验或准实验确认可干预效果。
主要局限：卖家-月存在组内相关；Copula只近似高阶依赖；缺少曝光、库存、促销和竞争变量；19个月限制长序列模型；低维稀疏场景下Knockoff+可能保守。
复现：随机种子{{SEED}}；面板SHA-256：{{PANEL_SHA256}}；完整代码、逐轮W、结果表和图位于“论文/v1”。
