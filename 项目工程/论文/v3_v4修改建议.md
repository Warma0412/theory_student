# V3 → V4 修改建议(审阅意见书)

> 对象:《面向电商 GMV 监控的可控错误发现维度选择研究(v3)》
> 审阅视角:统计学研究生学位论文;结合导师「多用近期 AI／深度学习」的要求。
> 底线:只提**真实需要修改**的地方,不做无谓挑刺;凡建议引入的方法,**均给出可核验的实际论文支撑**。全角中文标点。

---

## 一、V3 总体评价(先肯定,且要说清「为什么不能推倒」)

V3 已经是一篇**方法诚实度很高**的应用统计论文,几个做法在硕士层面是加分项,V4 必须原样保留:

- **主线严谨**:自然粒度先聚合再连接(避免 GMV 被支付／评价行重复)、次月 `log(1+GMV)` 目标(避免同月定义泄漏)、Copula-MVR 二阶 Model-X Knockoff + 60 次去随机化 e-BH(`α_eBH=0.20`、`α_kn=0.10`)。
- **结论分层清晰**:严格确认层(14 项)/ 高稳定层(10 项)/ 深度稳健层 / 预测解释层 / 参数化展示层,各层「结论权限」界定明确。
- **最难得的一点——公开否决失败结果**:深度生成器边际 KS 已降到 0.016,但 swap 分类器 AUC 仍高达 0.922,**未通过预设联合交换性门槛,于是明确不作 FDR 声明**;深度重要性 MLP 反对称误差 0.000e+00 但 0.20 水平选中 0 项;残差 MLP 的 RMSE 2.414 反而略差于 XGBoost 2.388——这些「不利结果」都被如实保留,而不是包装成卖点。

**这份诚实是 V3 的核心竞争力,V4 绝不能为了「显得 AI 更多」去牺牲它。** 因此本意见书的定位不是「加更多模型」,而是:**把 V3 已经点到、但只做了否定诊断或列为局限的几个真问题,升级成有论文支撑的正式方法尝试。**

## 二、核心判断:V4 真正的缺口在「方法深度」,不在「AI 数量」

通读全文,V3 有 **5 个真实的、非挑刺的方法软肋**,而且它们**恰好都能用近期论文来补**——这正好同时满足导师「多用近期 AI／深度学习」与「不能注水」两个要求。

| V3 自己承认的问题(原文位置) | 性质 | 有无现成论文可补 |
|---|---|---|
| 卖家-月存在**组内相关**,标准 Model-X 独立样本条件只是「近似」(7.4 局限 ②) | 统计有效性的最大软肋 | ✅ 有(聚类数据 Knockoff) |
| 深度生成器**联合交换性未通过**,只做了失败诊断(5.10) | 深度分支没「真正跑通」 | ✅ 有(DDLK 最坏情况 swap) |
| MMD 检验不拒绝、分类器检验强烈拒绝的**诊断口径矛盾**(5.10 原文自评) | 诊断工具功效不一致 | ✅ 有(深度核 MMD) |
| 订单数／件数／独立顾客数**高度共线**,仅在「展示层」归组,统计层仍逐个进入(3.5、6.2) | 共线代理相互稀释功效 | ✅ 有(group knockoff) |
| 配对竞争 MLP 反对称达标但**功效为 0**(5.11) | 深度重要性没产出结果 | ✅ 有(GRIP2 式重要性) |

一句话结论:
> V4 不要再加「新模型堆砌」,而应把上表 5 个已知软肋逐一用**对应论文的方法**补上。补 1–2 个即可显著提升论文的方法厚度与可信度;全补则从「应用报告」上升为「方法应用研究」。

## 三、具体修改建议(D1–D6)

每条给出:**现状 → 建议 → 为什么可信(论文)→ 工作量 / 落地口径**。凡新增实验结果,一律沿用 V3 的规矩标「待填」,以本机实跑 CSV 为准,不臆造数字。

### D1｜面板组内相关:补「聚类数据 Knockoff」稳健性情景(P0,最该做)
- **现状**:V3 在 7.4 明确承认「卖家-月行存在组内相关,标准 Model-X 的独立样本条件为近似」,但正文没有任何针对性处理,只把它列为局限。这是全文**统计有效性的最大软肋**,答辩极可能被问到。
- **建议**:新增一个**聚类数据 Knockoff 稳健性情景**——把每个观测级(level-1)特征分解为「卖家均值(between)」与「卖家内离差(within)」两部分,在**两个层级分别做 Knockoff 选择**,再与主结果比对入选集合是否稳定。
- **为什么可信**:Bacci、Grilli & Rampichini(2026,arXiv:2602.19398)《Variable selection via knockoffs for clustered data》正是为面板/重复测量这类聚类数据设计,提出「均值-离差分解 + 分层选择」两步法,并在模拟中比较 sequential knockoff、去随机化 knockoff 与 Lasso;论文明确指出**把 level-1、level-2 变量混在同一设计矩阵里做选择会失效,分层做才有效**。这与 V3 的卖家-月结构完全对应。
- **工作量 / 口径**:中等。作为**稳健性情景**加入 4.9 与 5.9,不动主结论;写清「主分析仍为整表 Copula-MVR,分层结果用于检验组内相关对入选集合的影响」。这一条即使只做出来「入选集合基本一致」,也是对最大软肋的正面回应。

### D2｜深度生成器:用 DDLK 的「最坏情况 swap」目标,给深度分支一次真正通过门槛的机会(P0)
- **现状**:V3 深度生成器的训练损失是**固定比例(20%/50%/80%)随机 swap 的 MMD + 边际 + 协方差**;结果边际 KS 降到 0.016,但 swap 分类器在各比例下 AUC 仍 0.90–0.99,**联合交换性被否决**。问题的本质是:固定几个 swap 比例下「平均」可交换,不代表**最坏那个 swap 子集**也可交换。
- **建议**:把深度生成器的训练目标从「固定比例 swap-MMD」升级为**最坏情况 swap 下最小化交换性违背**的对抗目标(用 Gumbel-Softmax 在 swap 子集上做可微搜索),即 DDLK 的核心机制。跑通后重新过 5.10 的联合诊断:**通过则深度分支首次可作 FDR 声明,不通过则否决结论比 V3 更硬**。
- **为什么可信**:Sudarshan、Tansey & Ranganath(2020,NeurIPS,arXiv:2007.15835)DDLK 的两阶段做法——先最大化特征似然,再用 **Gumbel-Softmax 在最坏情况 swap 下最小化 swap 性质隐含的 KL 散度**——恰好针对「某些 swap 子集仍可区分」这一 V3 的确切失败模式;论文报告在相同 FDR 下比基线选出更多真信号。V3 已在 [33] 引用 DDLK,但只是「借鉴思想」,并未真正采用其最坏情况 swap 目标——D2 就是把这条引用**落到实处**。
- **工作量 / 口径**:中偏高(要改损失与训练循环)。仍固定 V1 的 Lasso 惩罚系数、保持「查看选择结果前冻结准入门槛」的做法,避免调参自由度膨胀。

### D3｜交换性诊断:用「深度核 MMD」消除 MMD 与分类器的口径矛盾(P1)
- **现状**:V3 在 5.10 出现一个诊断悖论——**RBF-MMD permutation test 不拒绝(p 值多在 0.3–0.9),但 Extra Trees 分类器两样本检验强烈拒绝(AUC 0.9+)**。V3 自己解释为「固定带宽 RBF-MMD 对局部高维差异的功效低于灵活分类器」。这个解释成立,但**留着两个互相打架的诊断口径**在答辩时不利。
- **建议**:在诊断里把固定带宽 RBF-MMD **替换或补充为可学习的深度核 MMD**(用小型网络学核参数以最大化检验功效)。它介于「固定核 MMD」与「黑箱分类器」之间:既是**有原则的两样本检验统计量**(有明确的 permutation 零分布),又具备接近分类器的功效,从而给出**单一、自洽**的联合交换性判据。
- **为什么可信**:Liu、Xu、Lu、Zhang、Gretton & Sutherland(2020,ICML,arXiv:2002.09116)《Learning Deep Kernels for Non-Parametric Two-Sample Tests》提出用深度网络参数化核并训练以最大化检验功效,正是为「固定核功效不足、又想保留检验的统计严谨性」这一场景设计,且有开源实现。
- **工作量 / 口径**:中等。把它加进 4.12 的诊断清单,与现有 KS、协方差、分类器 AUC 并列;强调「深度核 MMD 用于诊断准入,不进入 W 统计量、不影响 FDR 证明链」。

### D4｜高共线代理:补 group knockoff,让 FDR 声明落在业务组上(P1)
- **现状**:成交订单数、成交件数、独立顾客数三者与次月 GMV 的 Spearman 都在 0.55 附近、彼此近共线;V3 只在 **6.2 展示层**把它们归入「交易规模模块」,**统计层仍逐个进入 Knockoff**。高相关代理会相互稀释功效(V3 自己在 5.5、6.5 提到低维稀疏下的离散门槛与 Rashomon 效应),也让「到底选哪一个」带有随机性。
- **建议**:新增一个 **group knockoff 情景**——按业务语义把 31 维分成「交易规模 / 价格成本 / 履约 / 内容供给 / 市场覆盖 / 支付结构」等组,做**组级 FDR 控制**,输出「哪些**组**是确认发现」。这既缓解共线稀释、提升功效,又让结论落在**业务可直接解释的组**上(和 6.2 的展示模块天然对齐)。
- **为什么可信**:Dai & Barber(2016,ICML,arXiv:1602.03589)《The knockoff filter for FDR control in group-sparse and multitask regression》提出 group knockoff,构造满足**组级可交换性**的仿制变量并在组层级控制 FDR,论文证明在特征成组时相对逐变量选择**功效更高**。
- **工作量 / 口径**:中等。作为稳健性/补充分析,与逐变量主结果并列呈现;说清「逐变量结论回答『哪个指标』,组级结论回答『哪类信息』,两者互补」。

### D5｜深度重要性:把配对 MLP 的 W 升级为 GRIP2 式重要性,解决「反对称达标但功效为 0」(P1)
- **现状**:V3 配对竞争 MLP 的反对称误差 0.000e+00(结构正确),但 0.20 水平**选中 0 项**——即深度重要性分支「合规但无产出」。原因正是高相关 + 低 SNR 下,单一正则强度、单超参的深度 Knockoff 重要性不稳、功效低。
- **建议**:把配对 MLP 的重要性统计量从「单次训练的配对权重」升级为 **沿优化轨迹、在二维正则曲面上积分 first-layer 活跃度**的聚合统计量(block-stochastic 采样,一次训练近似曲面积分),该统计量**天然反对称**,直接满足 FDR 前提。目标是在不破坏合规性的前提下**把功效从 0 拉起来**。
- **为什么可信**:Zou & Tian(2026,arXiv:2602.00218)GRIP2 明确针对「非线性、高相关、低信噪比」——**正是 V3 的数据 regime**——指出单一正则几何的深度 Knockoff 功效差,提出在二维正则曲面上积分重要性、by construction 反对称、保证有限样本 FDR 控制,并在高相关低 SNR 下保持功效与稳定性。V3 已在 [42] 引用 GRIP2,D5 是把它**从「可作对照与讨论」落成实际统计量**。
- **工作量 / 口径**:中偏高。仍作为**非线性稳健性证据**,不取代 Copula-Lasso 主结论;若升级后仍 0 项,则说明本数据的可控信号确以线性规模延续为主,这本身也是有价值的结论。

### D6｜两处「零成本」的严谨性收口(P0,必做且几乎不费力)
这两条不涉及新方法,但都是**真实的小漏洞**,改动成本近乎为零,却能挡住答辩时的尖锐提问:

1. **边际校准的信息泄漏**:V3 深度生成器的经验边际校准**使用了全体 $X$(含验证子集)的经验分位数**,V3 已在 7.4 承认这是验证复用风险。**建议 V4 把校准分位数只在训练子集拟合**,再应用到验证/测试,彻底消除这一泄漏点——与 3.7「所有分位点、中位数、标准化只在训练期拟合」的既有原则保持一致。
2. **swap 分类器 p 值恒为 0.010 的说明**:5.10 表 5-8 里所有分类器/MMD 的 p 值都等于 0.010,这几乎肯定是 **100 次 permutation 的下限分辨率**(即「≤0.01」而非「精确 0.010」)。**建议 V4 显式写明 permutation 次数**,并把 p 值记为「< 0.01(基于 N 次置换)」,避免被误读为「p 值恰好都相等」这类可疑现象。

## 六、诚实提示(务必遵守)

1. **保留 V3 全部真实数字**:14 677 观测、2 793 卖家、19 个月、GMV 12.342 百万雷亚尔、KS 0.013(全样本口径)/ 0.026(V2 验证子集口径)、深度生成器 KS 0.016 / swap AUC 0.922、XGBoost RMSE 2.388、残差 MLP 2.414、默认 K=10 测试 RMSE 2.385——V4 中原样保留,口径差异按 V3 现有做法说明清楚,不得抹平。
2. **新增实验一律标「待填」**:D1–D5 的任何结果必须本机实跑后填入真实 CSV,严禁臆造;跑不通/不通过就如实写「不通过」,这与 V3 现有的诚实基调一致,也是加分项。
3. **不为「多用 AI」而放宽统计准入**:D2/D5 的深度方法,只有**先通过冻结的准入门槛与反对称测试**,才有资格进入正式结论——这条 V3 已经做对了,V4 继续坚持。
4. **未来日期的预印本需作者核验**:arXiv:2512.04696、2602.00218、2602.19398 等为近期/预印本文献,作者须按学校规定核对原文、标注「预印本」并遵循 GB/T 7714 格式,避免答辩时被质疑时效性与可靠性。
5. **TFT 的降级维持不变**:19 个月序列不支持长期时序深度预测器,V3 的降级判断正确,V4 不要为了「显得 AI 多」而强行上 TFT——把深度学习用在它站得住脚的地方(横截面生成、重要性、诊断),这一原则从 V1→V2→V3 一贯正确。
