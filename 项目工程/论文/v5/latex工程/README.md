# 最终版交付说明

本目录包含相互独立、均可直接编译的论文、开题报告与开题汇报LaTeX工程。编译完成后，`build.sh`只把六个`.tex/.pdf`成品发布到项目根目录的`【最终版】/v5`。

## 论文

- 源文件：`论文/论文.tex`
- PDF：`论文/论文.pdf`
- 文档类：`论文/sufethesismas.cls`
- 图表与学校模板素材：`论文/figures/`
- 编译日志：`论文/论文.log`

论文使用上海财经大学应用统计专硕模板，内容包括中文摘要、英文摘要、目录、七章正文、45条参考文献、附录与致谢。封面中的学号和导师信息仍需按实际情况填写。

## 开题汇报

- 源文件：`开题汇报/开题汇报.tex`
- PDF：`开题汇报/开题汇报.pdf`
- 主题样式：`开题汇报/SUFE.sty`
- 图表与校名素材：`开题汇报/figures/`、`开题汇报/pic/`

汇报采用上海财经大学Beamer模板，共19页，包含研究背景、相关研究、数据设计、核心公式、真实结果、稳健性诊断、创新点、研究计划和主要参考文献。

## 开题报告

- 源文件：`开题报告/开题报告.tex`
- PDF：`开题报告/开题报告.pdf`

开题报告按照用户提供的`模板/吴优_开题报告.pdf`重建并扩展为14页A4：申请表、报告书封面、研究背景、文献现状、数据设计、完整算法公式、月度与周度真实结果表、深度诊断、创新与可行性、进度安排及25条主要参考文献。

## 编译

当前文件已使用Tectonic 0.17.0实际编译。进入对应目录后运行：

```bash
tectonic --keep-logs 论文.tex
tectonic --keep-logs 开题汇报.tex
tectonic --keep-logs 开题报告.tex
```

也可在完整TeX Live或MacTeX环境中使用XeLaTeX编译。
