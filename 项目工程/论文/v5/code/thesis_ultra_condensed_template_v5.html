2. 为什么仍以月度为主

  • 月度单元汇集更多订单，零成交率25.86%，较适合大量低频卖家。
  • 周度时间点更多，但下一周零成交率{{WEEK_ZERO_RATE}}，单订单周和共线代理更多。
  • 日度会进一步放大零膨胀、星期效应和偶发订单噪声，不适合作为本数据主线。
结论：月度承担确认性主分析；周度只检验结论是否依赖时间聚合粒度。

二、月周统一统计流程

1. 前瞻目标

Yₛ,ₜ₊₁ = log(1 + GMVₛ,ₜ₊₁)

用本月预测次月、用本周预测下一周。若当前期活跃而下一期无已送达订单，则目标记为零。同月GMV只作为机械关系对照，不作为主目标。

2. Model-X Knockoff

  1. 1%/99%缩尾、偏态变换、中位数插补与标准化；
  2. 随机化秩高斯Copula处理连续、计数、比例、二元及并列值；
  3. Ledoit-Wolf协方差与MVR准则生成每个变量的负对照；
  4. Lasso真实/仿制系数竞争：Wⱼ=|βⱼ|−|β̃ⱼ|；
  5. 重复60轮，聚合e-value后用e-BH控制最终FDR。
αkn=0.10；αeBH=0.20；重复M=60

4. 推断边界

Knockoff拒绝的是“给定其余维度后不再含预测信息”的条件零假设，不代表因果效应。周度分析采用最终已送达订单按购买周回溯归属；物流和评价在周末未必可见，因此不是严格在线部署模拟。

五、研究结论与论文口径

研究结果支持月度主分析的合理性，同时表明周度可用于粒度稳健性和短期预警，但不应替换更稳定的月度确认集。

2. 实际看板建议

  • 月度首页继续使用K参数，默认K={{V3_DEFAULT_K}}；季度滚动复核FDR集合。
  • 周度预警优先展示跨粒度且周度高稳定的10项，不把7项周度特有变量直接升级。
  • 订单数、件数、顾客数属于状态变量；履约、内容、价格等可行动项仍需实验确认。
  • 上线前按真实可见时间重构物流和评价特征，并进行滚动时间外回测。

3. 核心限制

Olist仅覆盖约19个月；周度卖家序列中位数仅{{WEEK_MEDIAN_ACTIVE}}个活跃周；面板存在组内相关；Copula只近似高阶联合分布；所有结果属于预测关联而非因果识别。

答辩一句话：月度降低稀疏噪声并承担确认，周度增加时间点并验证稳健性；11项交集是跨粒度证据，而不是新的因果结论。
