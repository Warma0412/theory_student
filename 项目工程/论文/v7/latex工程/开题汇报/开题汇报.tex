\begin{frame}{研究问题：有限容量的经营指标}
\begin{itemize}
\item 31项指标中选择8或12项，保留下一月目标的预测信息。
\item 同时评价预测、样本稳定性和模拟发现质量。
\item 不把预测筛选说成当期GMV分解或因果归因。
\end{itemize}
\end{frame}
\begin{frame}{文献与方法缺口}
\begin{itemize}
\item Deep Lasso 2023、VTFS 2024、TabM 2025提供不同非线性机制。
\item CPI和Semi-knockoffs 2026研究条件损失及双侧重建。
\item DeepPINK、DeepPIG、GRIP2已有成对深度研究。
\item 研究具体评分性质与组件增量，不把模型改名当创新。
\end{itemize}
\end{frame}
\begin{frame}{数据与时间可见性}
\begin{itemize}
\item Olist十张表，13,754个卖家月，2,723名卖家，31项指标。

\item 物流、评价和营销按月末已发生事件截断。

\begin{frame}{SCPL：背景不能偏袒真假身份}
\begin{itemize}
\item 固定训练好的预测器，评分集生成真假变量对。
\item 逐对取min/max，四组掩码及补掩码构成八背景。
\item 比较某列真假值时，其他列保持同一对称背景。
\item 比较平方损失差，再按卖家汇总。
\end{itemize}
\end{frame}
\begin{frame}{可证明的性质，不可越过的前提}
\begin{itemize}
\item 交换某列对：自身统计量反号，其他统计量不变。
\item min/max背景逐路径不变，损失输入互换即可证明。
\item 精确生成器下，随机背景边际与X同分布。
\item 不证明预测更准、生成器正确或真实FDR已控。
\end{itemize}
\end{frame}
\begin{frame}{机制消融与主候选}
\begin{itemize}
\item 同一预测器：普通、中点、随机对称、标准化四种评分。
\item 分别接入XGBoost和TabM，保留匹配线性对照。
\item 预定主候选是标准化TabM，不能事后换成最佳消融。
\item 八背景不等于八组独立Knockoff。
\end{itemize}
\end{frame}
\begin{frame}{模拟设计：800份而非挑选案例}
\begin{itemize}
\item 八场景各100次；n=2000，p=31，训练/评分/测试1200/400/400。
\item 全无效、线性、强弱非线性、纯交互、高相关、混合变换、t错设。
\item 七场景精确生成；t场景故意错设。
\item 全无效Power不定义，FDP和Power共同解释。
\end{itemize}
\end{frame}

\begin{frame}{真实FDR为什么不能保证}
\begin{itemize}
\item 估计Copula的交换分类AUC明显偏离.5。
\item 同卖家跨期相关，不满足简单独立评分理论。
\item MVR在看到参考结果后追加，必须披露后验性质。
\item 名义发现数增加不等于错误率控制更好。
\end{itemize}
\end{frame}
\begin{frame}{近期原文：Semi-knockoffs}
\begin{itemize}
\item 一侧条件于其他特征，另一侧再条件于响应。
\item 分别重建特征并打乱残差，比较固定预测器损失。
\item oracle条件矩已知时与估计条件矩的保证不同。
\item 作者代码无解阈值问题已纠正并保留反例。
\end{itemize}
\end{frame}
\begin{frame}{条件均值与尺度扩展}
\begin{itemize}
\item Ridge均值、非线性均值、条件尺度、联合四机制。
\item 针对仅靠线性均值可能漏掉平方与交互信息的问题。
\item 同一XGBoost/TabM、同一置换、同一评分样本。
\item 8项评分复算800份已有模拟，不冒称新800份数据。
\end{itemize}
\end{frame}

\begin{frame}{结论与下一步}
\begin{itemize}
\item 已形成明确算法问题、性质、拆分消融和完整实测。
\item 没有证据支持复杂方法全面领先或真实FDR无条件受控。
\item 补近期非线性受控基线及未使用真实数据的冻结验证。
