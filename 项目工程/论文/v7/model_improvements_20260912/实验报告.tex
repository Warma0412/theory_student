本研究是已观察V7结果之后的探索，不是外部预注册验证。新改动均完整执行，不能把一次改动的局部收益说成世界首创或跨数据集普遍优势。V7原论文、CSV、模型和失败记录没有覆盖。

新增十个方法/消融配置，各完成111个主预算真实案例、一个8项参考案例及600个模拟案例，合计1,120个新真实选择案例、6,000个新模拟案例、40组初始预测文件。旧八方法的选择结果作为历史基线读取，不冒充选择器重新训练。所有18种方法与全维基线随后共同按规范列顺序重评，形成74组预测文件。完整原始表构建的13,754行卖家月面板未抽小；外层抽样是评价的一部分。

\section{四条模型改动}\label{ux56dbux6761ux6a21ux578bux6539ux52a8}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{Deep Lasso-Jacobian}：原梯度分数同时乘有残差，容易使误差大的样本支配重要性。改为预测函数Jacobian的按列RMS稀疏目标，并用相同Jacobian排序。另做``只改排序''和``改训练但保留原排名''两项消融。导数正则已有长期文献，不能称为首次提出。
\item
  \textbf{TabM-预算门}：在官方8成员TabM前加入共享的精确K硬门，反向传播使用约束sigmoid软门的直通梯度；15轮全变量预热后开始预算训练。解决训练看31项、最终只留K项的不一致。输入门与直通估计均有先例，本实现是局部预算约束适配。
\item
  \textbf{EntryPrune-刷新/环境波动惩罚}：原发布代码记住候选历史最高进入分数。刷新版用三个训练时间块的当前梯度均分并重置再生列Adam动量，波动版再扣除环境间标准差。刷新版和波动版共享除波动项之外的改动；这不是具有覆盖保证的置信下界。回归输出和对齐最佳检查点是共同适配，不列为创新。
\item
  \textbf{VTFS-固定K/成对损失}：固定K语料与定长唯一token解码消除不同长度和任意前缀造成的预算偏差；新增按效用差加权的成对logistic排序损失。用同样128次子集查询的随机搜索检验Transformer是否带来额外收益。固定K修复本身不冒称原论文的新发现。
\end{enumerate}

官方组件：Deep Lasso官方正则与V7 MLP；TabM 0.0.3；EntryPrune锁定commit；VTFS官方编码/解码骨干（仍保留epsilon=1）。所有路径与摘要见source\_manifest.json。

\subsection{各改动的实际判断}\label{ux5404ux6539ux52a8ux7684ux5b9eux9645ux5224ux65ad}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{Deep Lasso-Jacobian：有局部价值，尚非全面提升。} 相对完整名单的半样本Jaccard从原版0.8230升至0.8618，但相对父方法的互补半样本增量区间跨0，参考Jaccard增量经族内校正后也跨0。相对SHAP的两种Jaccard差异较明确；其平均FDP为0.2657、Power为0.8978，仍弱于SHAP的0.2315和0.9403。适合跟进稳定性取舍，不支持全面优胜或新定理。
\item
  \textbf{TabM预算门：不支持综合改善。} 参考Jaccard从0.7505升至0.8071，但互补一致性和Nogueira没有同步提高，模拟FDP从0.2656升至0.2793。不能只选参考Jaccard作为成功标准。
\item
  \textbf{EntryPrune刷新与波动惩罚：本实现不宜作为提升主线。} 波动版相对回归父实现的参考Jaccard从0.6271降至0.4498，Power从0.8729降至0.6263。即使一个评价器的误差点估计更低，也不能掩盖选择质量恶化。刷新涉及分数与动量两项变化，不能将失败单独归因于其中一项。
\item
  \textbf{VTFS：预算匹配有模拟收益，成对损失独立证据较弱。} 原适配、固定K、固定K加成对损失的平均FDP依次为0.5306、0.4593、0.4531，Power依次为0.5876、0.6815、0.6901。主要收益来自预算修正；成对损失较固定K版本仅小幅增量。二者真实数据预测与稳定性尚未形成优势，修复旧适配不应包装成原创模型成功。
\end{enumerate}

结论：没有发现同时在预测、两类样本稳定性与模拟检出方面全面超过强基线的新算法。计算完成和某项指标变好，都不能自动证明论文原创性。

\subsection{可以检验的机制问题}\label{ux53efux4ee5ux68c0ux9a8cux7684ux673aux5236ux95eeux9898}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  对平方损失，输入损失梯度是预测Jacobian与残差的乘积。较大残差样本可能放大某列分数。Jacobian稀疏/排名试验检验去除这一权重的收益与代价，不能先验保证其错误发现率更低。
\item
  普通TabM在全部31项上训练，再删除多数特征。固定K共享门把预算嵌入训练，检验减少训练与使用阶段不一致是否有收益。直通估计是有偏梯度近似，不能说本轮精确求解非凸最优子集。
\item
  EntryPrune的历史最大分数可能受到偶然梯度高分影响。刷新与波动惩罚尝试控制这一问题，但反复对同一批数据打分不产生独立统计证据，均值减标准差不是有效置信下界。
\item
  固定K语料首先纠正VTFS适配的预算不匹配；成对效用差损失尝试让连续表示更关注子集优劣。学习排序也是已有思想，必须以``固定K版本''作父对照，不能把修复带来的收益归给新增成对损失。
\end{enumerate}

\subsection{哪些不足以支撑论文创新}\label{ux54eaux4e9bux4e0dux8db3ux4ee5ux652fux6491ux8bbaux6587ux521bux65b0}

\begin{itemize}
\tightlist
\item
  调大网络、改学习率、换一个随机种子；
\item
  把已有正则、门控、相关聚类简单合并并另起名字；
\item
  修复当前实现问题后只与有问题的旧实现比较；
\item
  只报告一种指标、一个K或最有利模拟场景；
\item
  某次预测点估计较好，就声称稳定性或FDR理论也成立。
\end{itemize}

\subsection{进入正式论文的条件}\label{ux8fdbux5165ux6b63ux5f0fux8bbaux6587ux7684ux6761ux4ef6}

机制必须有独立动机、相邻工作辨析、拆分消融和稳定的样本外证据。优于较弱父方法还不够，需要与XGBoost-SHAP等强基线对比。对新的真实数据进行冻结后验证仍是缺口。本轮结果可为``哪些机制值得继续研究''提供证据，不能替代导师对研究贡献与学位要求的判断。
